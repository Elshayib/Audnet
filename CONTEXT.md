# Audnet

Audnet is an open-source auditor of live network-device configuration against a security baseline. It exists so operators can detect configuration drift on networks they own.

## Language

**Operator**:
The person who owns and runs the devices being audited.
_Avoid_: Auditor, MSP, tenant, customer

**Device**:
A router, switch, or firewall whose live configuration is collected and checked.
_Avoid_: Host, node, box
